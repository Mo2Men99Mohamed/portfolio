Email Phishing Investigation Tool [CASE-03]
tool · shipped

A Python tool (Tkinter GUI + CLI) that ingests a raw .eml file and runs it through a structured 7-step phishing-investigation playbook, scoring risk automatically.

> ANALYSIS ENGINE: Header parsing, SPF/DKIM validation, URL/attachment extraction
> INTEGRATIONS: VirusTotal v3 API, AbuseIPDB API, WHOIS domain lookup
> OUTPUT: Generates markdown forensic reports with risk scoring.
  • Sender, SPF/DKIM/DMARC, mail-path, Return-Path/Reply-To, URL, attachment, and body analysis — each scored per a weighted risk model.
  • Algorithmic typosquat/brand-impersonation detection, double-extension and macro-attachment triage, and link/button-text mismatch detection.
  • Optional WHOIS/VirusTotal/AbuseIPDB enrichment with graceful fallback, and a full Markdown/JSON case report with a Legitimate/Spam/Phishing/Malware verdict.
